npm run verify

AI Career Agent is a local job-search automation tool. It scans Gmail job-alert emails, supports Manual JD Scan, uses LinkedIn browser sessions when needed, evaluates jobs against `cv.md` and `config/profile.yml`, generates Markdown reports and executive DOCX reports, and never submits applications automatically.
