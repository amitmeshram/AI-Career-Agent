# AI Career Agent Code of Conduct

AI Career Agent is a local project. Collaboration should remain respectful, practical, and focused on improving the tool without exposing private user data.

## Expected Behavior

- Be respectful and factual.
- Protect private files, credentials, tokens, CV data, reports, runtime data, and browser sessions.
- Keep discussion focused on the current AI Career Agent workflow.
- Do not pressure users to submit applications or mass-apply.

## Unacceptable Behavior

- Sharing secrets or private user data.
- Adding or encouraging automatic application submission.
- Misrepresenting generated or invented CV facts as true.
- Harassment, abuse, or personal attacks.

## Enforcement

The current repository owner or maintainer decides how to handle violations in this local project.
